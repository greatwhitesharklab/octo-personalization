# EXPERIMENTS — octo 实验旅程（run-271 → run-279）

「机制护城河」假设如何被**一步步否证**。全程合成数据机制验证；能力结论待真实语料。负结果即重点。

## 问题
冻结小模型＋外部每用户记忆做千人千面（催收/营销）：有没有**可防御的机制护城河**（别人抄不走）？
测了三个候选，全失败。有效杠杆结果是可抄的胶。

## 旅程
- **run-271 现代腔控制**：细粒度词汇人格难；**韵律比词汇签名更好 steer**。语气可控但不独特→语气是 commodity。
- **run-272 共情态推断**：6 态 playbook＋消歧提示 v2 区分焦虑/哭穷/表面愤怒；4B 焦虑 0/3→3/3（总 0.944），27B 1.000。**提示可解**→有用但非护城河。
- **run-273 ReFT 风格干预**：LoReFT（rank8/L19/~20k）**内容保持**（repeat 0.008 vs 加法 α2 0.126/0.159 塌）。干净工具→run-279 复用，失败。
- **run-274 个性化杠杆**：**富画像＋强制引用** JEV-personal **0.304→0.500**。杠杆真实。**⚠️ 量具 bug**：合规判官金额归一化保留单位（`320元`≠`320`）→假幻觉旗标＋伪造「强个性化×合规权衡」；修成只留数字后权衡**边际不强**。**教训：先验量具。**
- **run-275 竞品扫描**：五阈值①显著检索②强制利用③异步巩固④grounding⑤个性化×合规；缺口②④⑤。
- **run-276 Memobase 实测**：②利用**✗**——原生指令「除非用户问否则别主动提记忆」**抑制主动利用**；强制引用 personal 0.371→0.554。缺口真实但修法是提示杠杆（胶）。
- **run-277 原型 A（胶脚手架）**：P0 personal 0.497/违规 3；P1 修复环违规 1。但 coo1 型**自造分期数学**（3849.75/1283.25）提示修复停不住→派生数字是硬残余→ motivates 原生测。
- **run-278 原生 grounding B（K/V 注入）**：Arm0 无适配器读出失败＝**配置错误**（漏共享读出适配器，W62 早证无适配器≈17.5%），当天更正。Arm1 带适配器 coo 两案 K2 零自造看似有戏；**扩到焦虑案否证**：K2 编出与注入事实**矛盾**的数（月薪 2000→2685；账户 3200→14970）。K/V 压幻觉**随案型变、不可靠**。副测：1650 fp16 offload≈CPU（0.87 tok/s，4GB 仅 10/36 模块）→**无提速**。**事实可用≠忠实吐出；候选#2 否证。**
- **run-279 编排护城河测（GPU 批次）**：120 合成案（train90/eval30），ReFT 利用 30/60/90 三档。利用缺口真实 A **0.076**→B **0.238**（~3×）；**C 学习 0.173/0.146/0.154 全低于 B、随数据平/降**；C 更合规但个性化更低＝权衡另一点。**学习编排≤胶、无数据复利→候选#3 否证。**

## 负结果时间线（护城河怎么死的）
| 候选护城河 | 死于 | 判定 |
|---|---|---|
| 独特语气机制 | run-271/273 | commodity |
| 原生精确 K/V grounding | run-278（confabulation） | 不可靠 |
| 学习编排＋数据飞轮 | run-279（C≤B、scaling 平） | ≤胶、无复利 |

## 幸存
- **个性化杠杆**（富画像＋强制引用~3×）——真实可复现，但**胶/可抄**。
- **态推断**（提示可解）——有用非护城河。
- **诚实结论**：可防御优势**不在机制**，在**累积客户数据＋产品场景＋编排 know-how**（时间堆的）。

## 贯穿教训
1. **先验量具**（run-274 norm bug 伪造权衡）。
2. **小样本会骗人**（run-278 coo-only 零自造是运气）。
3. **复用需前置件**（run-278 漏适配器→退化）。
4. **合成＝仅机制**；能力须真实语料。
5. **失败的机制也是结果**——发布否证即贡献。
